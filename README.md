# 程一鸣 · Yiming Cheng

中英双语个人主页，基于原生 HTML、CSS、JavaScript。保留简历中的教育、实习和研究项目，新增用户提供的个人介绍与学校邮箱。白色与浅蓝背景、深蓝标题，适配手机与电脑。

## 本地运行

需要 Node.js 20 或更高版本，无第三方依赖，无需 `npm install`。

```sh
cd /workspace/personal-website
npm run dev
```

在运行机器上访问 `http://localhost:3000`。服务监听 `0.0.0.0:3000`；云环境使用其支持的端口预览方式。可通过 `PORT=3001 npm run dev` 更换端口。

## 构建

```sh
npm run build
npm run preview
```

产物输出到 `dist/`。预览前停止同端口开发服务，或运行 `PORT=3001 npm run preview`。构建命令与 `vercel.json` 保持一致。已有 Vercel 项目可在 GitHub `main` 更新后自动构建；不需要新增项目、环境变量或数据库。

## 内容与维护

- `app.js`：`content.zh` / `content.en` 存放双语内容，`emails` 数组统一管理两个邮箱及其复制按钮。
- `styles.css`：白蓝主题、响应式布局、键盘焦点、减少动画偏好与打印样式。
- `index.html`：入口及静态元信息；禁用 JavaScript 时仍可查看两个邮箱。
- `scripts/serve.mjs`：本地开发和产物预览服务器。
- `scripts/build.mjs`：复制网站文件至 `dist/`。

语言偏好只存储在浏览器本地。经历和项目详情使用原生展开控件。两个邮箱均支持邮件链接与独立复制反馈；复制权限不可用时提示手动选择。学校个人主页在新标签页打开，并设置 `noopener noreferrer`。

## 信息来源与当前限制

教育、实习、研究项目的机构、日期、职位与成果数字依据提供的简历保留。博士二年级、AI 行业与科技投资兴趣、毕业后养小狗或小猫的愿望，以及学校邮箱均由用户本次提供。无论文、社交账号或其他个人信息的补充推断。

已删除所有号码与可拨打链接，仅展示常用邮箱和学校邮箱。原始 PDF 不属于网站资源。简历中的到岗安排未作为当前状态展示。

本轮消息中可见头像，但云环境没有可读取或下载的原始图片文件，因此尚未添加头像，也没有使用替代图片。需重新上传 PNG/JPG 原文件后，原样保存到静态资源目录，并加入构建复制步骤、清晰度与加载检查。
