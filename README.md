# 程一鸣 · Yiming Cheng

中英双语个人主页，基于原生 HTML、CSS、JavaScript。保留简历中的教育、实习和研究项目，新增用户提供的个人介绍与学校邮箱。采用编辑式极简布局：纯白背景、深海军蓝文字、克制的蓝色链接，适配手机、平板与电脑。

## 本地运行

需要 Node.js 20 或更高版本，无第三方依赖，无需 `npm install`。

```sh
cd /workspace/personal-website
npm run dev
```

在运行机器上访问 `http://localhost:3000`。服务监听 `0.0.0.0:3000`；云环境使用其支持的端口预览方式。可通过 `PORT=3001 npm run dev` 更换端口。

## 构建

```sh
npm run build
npm run preview
```

产物输出到 `dist/`。预览前停止同端口开发服务，或运行 `PORT=3001 npm run preview`。构建命令与 `vercel.json` 保持一致。已有 Vercel 项目可在 GitHub `main` 更新后自动构建；不需要新增项目、环境变量或数据库。

## 内容与维护

- `app.js`：`content.zh` / `content.en` 存放双语内容，`emails` 数组统一管理两个邮箱及其复制按钮。
- `styles.css`：统一的字体和留白体系、响应式编辑网格、键盘焦点、减少动画偏好与打印样式。
- `index.html`：入口及静态元信息；禁用 JavaScript 时仍可查看两个邮箱。
- `scripts/serve.mjs`：本地开发和产物预览服务器。
- `scripts/build.mjs`：清理旧产物、复制网站文件，并将 `assets/` 中的图片原样复制到 `dist/assets/`；不发布资源目录中的说明文件。

首页只展示姓名、身份、兴趣、经历概览和一个主要导航入口，教育背景保留在独立板块。所有编号、标签式技能和带边框的内容卡片已移除；研究使用项目列表，技能使用分组文字。

语言偏好只存储在浏览器本地。经历和项目详情使用原生展开控件，默认收起，切换语言时保留展开状态。两个邮箱均支持邮件链接与独立复制反馈；复制权限不可用时提示手动选择。学校个人主页在新标签页打开，并设置 `noopener noreferrer`。

## 信息来源与当前限制

教育、实习、研究项目的机构、日期、职位与成果数字依据提供的简历保留。博士二年级、AI 行业与科技投资兴趣、毕业后养小狗或小猫的愿望，以及学校邮箱均由用户本次提供。无论文、社交账号或其他个人信息的补充推断。

已删除所有号码与可拨打链接，仅展示常用邮箱和学校邮箱。原始 PDF 不属于网站资源。简历中的到岗安排未作为当前状态展示。

头像在聊天中可见，但云环境中尚无可读取或下载的原始图片文件。首页保留了小尺寸方形头像位置，没有生成或采用替代图片，也不请求不存在的图片。取得原文件后，将其原样保存到 `assets/`，把 `app.js` 中的 `portraitSrc` 从 `null` 改成对应路径（例如 `assets/avatar.jpg`），即可通过现有构建自动复制发布。`object-fit: contain` 保留完整画面；接入后仍需检查实际清晰度、原图校验值及桌面/手机加载。

## 验证

本轮检查逐项比较重构前后的整个双语内容数据，确认内容完全一致，并在 Chromium 中展开所有经历与项目，核对机构、时间和全部事实文本。浏览器验证覆盖双邮箱复制及失败反馈、邮件链接、学校主页新标签页配置、展开状态跨语言保留、语言记忆、手机菜单、Escape 关闭及全部内部锚点。两种语言在 320、375、390、600、768、900、1024、1440 像素宽度下均无水平溢出。静态构建、产物预览和 JavaScript 语法检查通过；实际头像加载因缺少原文件未验证。

学校主页地址按用户提供的原链接保留。云环境代理拒绝该域名的 CONNECT 请求（403），因此仅验证链接配置与打开方式，未能验证目标页面的实际响应。
